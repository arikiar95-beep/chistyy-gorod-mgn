# Чистый город — автомойка в Магнитогорске

Адаптивный сайт с плавным появлением секций при прокрутке, анимированным первым экраном, бегущей строкой и интерактивными карточками.

## Запуск
Откройте index.html или запустите из папки проекта: python -m http.server 8080

Сборка и установка зависимостей не нужны. Загрузите все файлы вместе на любой статический хостинг. Кнопки звонка, почты и маршрута работают без сервера.

## Содержание
- index.html — страница сайта
- style.css — оформление, адаптивность и анимации
- app.js — меню, появление секций и переключение анимации
- wash.jpg — тематическая иллюстрация, не фото объекта
- favicon.svg — иконка
